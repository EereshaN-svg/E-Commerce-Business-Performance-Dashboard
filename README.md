# E-Commerce Business Performance Dashboard

## 📊 Project Overview

An interactive **Power BI dashboard** designed to analyze e-commerce business performance and provide clear insights into sales, profit, customers, orders, returns, targets, categories, products, and regional performance.

## 🎯 Key KPIs

- 💰 Total Sales: 37.63M
- 🛒 Total Orders: 12K
- 👥 Total Customers: 2K
- 💵 Total Profit: 11.29M
- 📈 Profit Margin: 30%
- 🔄 Return Rate: 3%
- 🎯 Target Achievement: 7.9%

## 📌 Dashboard Analysis

- Monthly Sales Trend
- Sales by Category
- Order Status Mix
- Total Sales by Region
- Top 8 Products by Sales
- Interactive Date Filter
- Category and Region Filters

## 🛠️ Tools & Skills

Power BI, DAX, Power Query, Data Modeling, Data Visualization, Microsoft Excel, Business Intelligence, Data Analysis
